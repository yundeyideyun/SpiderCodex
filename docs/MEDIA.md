# 媒体包与许可

引擎代码、Microsoft WebView2 SDK、Node 运行时、Spider-Man 人物／视频／原参考动效是不同来源，不能用一个代码许可证统一覆盖。

当前本地复核包使用用户交接的参考视频提取蛛丝、面罩、眼睛、标题和圆环，以及用户提供的 4K 动态壁纸。客户端背景由既有参考图经确定性对齐、亮度恢复和局部修补获得，不是原作者的原始透明素材或完整高清工程。公开分发权限尚未确认；不因用户提供文件就推断第三方素材可开源分发。

运行媒体结构保持独立：assets/city.mp4 为桌面视频；client-brighter.png 为客户端连续背景；desktop-v8.html 为场景入口；v5 保存蛛丝／面罩／标题／圆环与几何元数据；v6 保存红丝收拢及 GPU 合成代码。prepare-release 脚本内列出最小运行清单，检查缺失文件并生成包内 SHA256 清单。

默认壁纸的两张毛玻璃纹理可在打包前用 `node scripts/prepare-glass-textures.mjs <Chromium 可执行文件>` 生成。客户端只在壁纸和两张纹理的 SHA256 均匹配时直接使用成品。自有媒体包和缺少成品的旧安装仍可现场生成同样的纹理。终端使用者无需安装 Chromium。

当前收拢直接使用参考动作，已移除重复的二次缩放与平移；等待真实客户端时暂停静态阶段绘制，进入文字支持点击或等待。背景的恢复保持原构图，不启用被用户否决的右侧独立图片或生成扩图。

干净源码导出包含场景程序代码，不包含参考 PNG、MP4、ICO 与用户截图。本地媒体包已经可以在构建时导入。运行时换肤界面与参考媒体的公开分发许可仍待完成。

R43 的发射、扩网、收拢以参考录屏的 60 fps 采样。v6/red-color.mp4 保存粉红至深红的颜色变化，与收拢透明度视频配对。


从有权使用的素材目录生成媒体包可运行：

    node scripts/media-pack.mjs pack <素材目录> <新的媒体包目录>

用 `node scripts/media-pack.mjs verify <媒体包目录>` 可核验文件名、SHA256、PNG 尺寸和数据块、MP4 容器、ICO 图像目录及场景几何。`check <素材目录>` 在生成媒体包之前运行同样的结构检查，直接从项目素材打包也会检查。媒体目录保留原有 v5、v6 子目录。控制程序和 HTML 属于源码，由构建脚本复制。媒体包只提供清单中的 PNG、MP4、ICO 和几何数据 JSON。

构建时向 `scripts/prepare-release.ps1` 传入 `-AssetPackDirectory <媒体包目录> -LocalPreview`，或向 `scripts/prepare-install-kit.ps1` 传入同一个媒体包路径。构建后仍应打开本地预览，验证系统能解码素材并按预期显示。SHA256 用于检查文件一致性，分发许可需要单独确认。
