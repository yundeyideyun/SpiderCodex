# 贡献约定

保持官方客户端的真实功能与已有用户状态。不得通过关闭正在执行任务的客户端、修改其安装包、复制认证缓存、改代理或降级安全防护来让视觉测试通过。

先复刻参考中的构图、材质和时序，再讨论改进。顶部菜单与窄图标列保留连续背景，只增加亮度和饱和度；项目／历史列表与聊天连成一体；输入框可用轻薄毛玻璃，回复以透明为主。拒绝把主体改为右侧独立海报、实色分栏或过度裁切。

每项改动附上有边界的验证：源码实现、替身测试、真实原生操作、实际登录状态、完整端到端验收分别说明。发现失败时保留失败记录；后续成功记录注明修正范围，不覆盖历史失败来制造全部通过。

UI 自动化必须以独立数据目录、独立端口和动态进程身份保护为前提。旧的操作当前聊天的测试入口已禁用；不能为了省事重新启用或发送 Esc。

发行物使用全新目录构建，生成文件清单和 SHA256 后验证。已运行文件不就地覆盖，旧版本保留到升级与回滚验证完成。源码导出采用允许清单；勿提交账户、项目列表、聊天内容、截图、缓存、原作者客户端代码与未经确认可分发的素材。

项目尚未完成公开发布验收，代码许可证和媒体许可分别待确认。当前无公开仓库或自动发布步骤。
