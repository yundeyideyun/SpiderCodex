# SpiderCodex

Windows 官方 Codex 客户端的本地主题、动态桌面与启动交互工程。保留官方客户端功能，通过本机连接接入视觉层，不修改已安装的官方程序文件。

**Windows 1.0 源码交接。** 本机验收清单共 91 项，63 项已通过，28 项待验收。安装、卸载、重装和同版更新已复测。账号与工作空间切换、不同显卡与多屏环境仍有待验收项。代码尚未选择开源许可证。

本地预览在 Windows x64 上验证。客户端皮肤需要当前 Windows 用户安装的官方 Codex、.NET Framework 4 和 Node.js 22 或更新版本。含便携 Node 的安装包自带锁定版本；本地构建也可以使用系统 Node。启动入口读取官方包清单。Microsoft Edge WebView2 Runtime 用于桌面壁纸和开场；它不可用时，皮肤仍可使用。主题所需的 Node 不可用时，桌面入口打开原生客户端。

构建参见 [docs/BUILD.md](docs/BUILD.md)，测试参见 [docs/TESTING.md](docs/TESTING.md)，媒体与许可参见 [docs/MEDIA.md](docs/MEDIA.md)。完整要求保留在 `需求与验收清单.json`。

桌面入口默认启用轻量模式，加载客户端皮肤、静态壁纸玻璃及窗口缩放保护。缩放保护不再依赖完整特效开关。4K 动态桌面和启动动画可在启动命令中加 `--full-effects` 启用。新增参数在下一次启动新会话时生效。

输入框、设置和菜单共享与原背景对齐的通透材质。大面积表面复用预处理纹理和短图片引用，小浮层仅作轻微实时模糊；不会在滚动正文时反复模糊整块界面。悬浮进入时，按钮抬升，配合接触投影、柔和反光与弹性回落，不添加水波纹。菜单行保持原有位置与边界，由内部图标／文字浮起。发送、停止及语音状态保留各自语义。系统开启减少动态效果时，关闭新增扫光和位移动画。

整行列表保持点击范围不动，由内部透明表面与文字浮起，避免放大后裁掉文字；反光按实际圆角容器裁切。紧凑文字按钮保留文字和箭头留白，开关沿用胶囊轮廓，文件卡片与底部折叠行共享圆角。已有外壳的状态标签、运行记录和文件摘要只由一层显示高亮，不给透明点击层再套阴影。小标签使用较轻的近距离投影，避免出现厚底座。聊天自动滚动不会清掉无关侧栏的悬浮效果。

首次启用皮肤时，请先完成正在进行的工作，通过官方客户端的“文件 → 退出”完全关闭它，再从 Spider Codex 图标打开。点击窗口右上角的关闭按钮可能只会关窗，官方客户端仍留在后台。登录、账号和工作空间继续由官方客户端处理。

## 官方客户端更新或增加功能时

官方客户端继续通过其正常渠道更新。SpiderCodex 每次启动都读取 Windows 当前登记的官方版本和入口。当前发行版的皮肤适用于已复核的版本。遇到未复核的版本或入口变化，桌面快捷方式优先通过 Windows 登记的官方应用入口打开原生客户端。若登记信息不足以唯一确认入口，可从 Windows 开始菜单打开官方 Codex。

同一个官方版本也可能陆续加入新功能。已识别的工作区、设置和登录界面继续使用相应皮肤。遇到无法识别的新页面，皮肤会暂时停用，回到已识别页面时自动恢复。新增页面及控件先使用官方功能，适配随通过复测的项目版本交付。

已有页面里的标准菜单和控件可复用相同的悬浮、高光、焦点和圆角。新页面纳入支持范围时，同样按这套尺度逐项验收，包括窄窗、子菜单与禁用状态。

运行 `SpiderCodex.exe --diagnose` 后，可在 `%LOCALAPPDATA%\SpiderCodex\diagnostics.json` 查看官方版本、兼容状态和原因。版本管理用于已经复核过的官方客户端与皮肤组合。维护者按更新复测步骤核对新版本，再更新相容版本记录。[更新复测步骤](docs/TESTING.md#官方更新与新功能复测)

代码许可证尚待项目所有者选择；第三方软件许可证与参考视频、美术素材权利单独记录。干净源码导出不包含官方客户端代码、凭据、账户缓存、聊天截图或参考媒体。未经确认分发权限的媒体不会被标记为公开发行资源。

打开安装目录里的“版本管理.exe”，选择已有版本并点击“应用版本”。程序会逐个检查所选版本的文件，再保存选择。当前客户端完全退出后，下次从原图标启动时生效。
